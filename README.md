# Battery-State-of-Health-Analysis
LAPTOP BATTERY STATE OF HEALTH (SOH) ANALYSIS MATLAB-Based Battery Health 

1. ABSTRACT

Battery health is an important parameter for evaluating the remaining performance and usable capacity of a rechargeable battery. This project presents a MATLAB-based method for analyzing laptop battery health using the battery information generated by the Windows operating system.

The Windows Battery Report provides important battery parameters, including the original design capacity and the current full charge capacity. MATLAB is used to read and process this report, extract the required battery parameters, calculate the Battery State of Health (SOH), determine capacity degradation, and visualize the result.

For the tested laptop, the measured design capacity was 40,230 mWh, while the current full charge capacity was 26,325 mWh. Based on these values, the calculated battery SOH was 65.44%, with a capacity loss of 34.56%.

2. INTRODUCTION

Rechargeable batteries gradually lose their ability to store energy as they undergo charging and discharging cycles. Monitoring battery health helps users understand battery degradation and can support maintenance and replacement decisions.

The State of Health (SOH) is commonly used as an indicator of the remaining battery capacity compared with its original rated capacity.

In this project, a Windows laptop battery report is used as the input source. MATLAB processes the report and calculates the battery SOH automatically.

7. STATE OF HEALTH CALCULATION

Battery State of Health is calculated using:

SOH (%) = (Full Charge Capacity / Design Capacity) × 100

Substituting the measured values:

SOH = (26,325 / 40,230) × 100

Therefore:

Battery SOH = 65.44%
8. CAPACITY LOSS CALCULATION

The capacity lost by the battery is calculated as:

Capacity Loss = Design Capacity − Full Charge Capacity

Therefore:

Capacity Loss = 40,230 − 26,325

Capacity Loss = 13,905 mWh

The percentage capacity loss is:

Capacity Loss (%) = (13,905 / 40,230) × 100

Capacity Loss = 34.56%

12. RESULT ANALYSIS

The laptop battery has a design capacity of 40.23 Wh and currently provides a full charge capacity of approximately 26.33 Wh.

The calculated SOH is 65.44%.

This means the battery currently retains approximately 65.44% of its original measured capacity, while approximately 34.56% of the original capacity has been lost.

The SOH value is a capacity-based measurement. Actual battery replacement decisions should also consider factors such as battery runtime, charging behavior, unexpected shutdowns, physical battery condition, and manufacturer/service recommendations.
